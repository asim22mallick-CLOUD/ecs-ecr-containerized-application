# Containerized Application Deployment using Amazon ECS & ECR

## Overview

Designed and deployed containerized applications on AWS using Docker, Amazon ECS, and Amazon ECR, with both ECS EC2 and AWS Fargate launch types.

## AWS Services

Amazon ECS • Amazon ECR • EC2 • AWS Fargate • ALB • IAM

## What I Built

- Built Docker images and pushed application images to Amazon ECR.
- Deployed containerized workloads using Amazon ECS with both EC2 and Fargate launch types.
- Configured ECS Task Definitions, Services, and Application Load Balancer for application delivery.
- Managed container image versions and validated application health and service availability.
